# Persisted miniapps

## Create and edit

- artifact_create: miniapps use {artifact_type:"custom", title, html, css?, data:{}}. Implement working interactions and persistence. chart and task-tracker also accept HTML. Only an explicit static-document request uses {artifact_type:"document", title, content:Markdown}.
- artifact_get: {resource_id} returns state, resourceId, version and metadata. Read before editing.
- artifact_update_state: {resource_id, artifact_type?, content?, html?, css?, data?, expected_version?}. Only supplied fields change. content replaces document Markdown. html replaces interactive HTML, css replaces its stylesheet. artifact_type=custom plus html explicitly converts a document into a miniapp without changing its resource ID. data REPLACES the complete object, including removing absent keys. expected_version rejects changes made since the read; read again and reconcile.
- artifact_merge_data: {resource_id, data_patch:{...}} shallow-merges keys atomically into current data. Nested objects are replaced per key. It preserves HTML and CSS.
- artifact_list: optional project_id; returns existing artifacts.
- artifact_delete: {resource_id}; removes the artifact when requested by the user.
- artifact_link_resource: {artifact_resource_id, linked_resource_id}; links a spreadsheet or null to unlink. Sheet data appears as DOME_DATA.linkedData.sheets[sheetName]. Refresh data rereads the linked source.

## Interactive contract

html is a BODY FRAGMENT, not a full document. Use inline styles, markup and scripts. Dome installs the theme, storage shim and data bridge BEFORE author scripts. Render from window.DOME_DATA. After every meaningful change call window.__dome_updateState(fullNextDataObject). Define window.dome_onDataRefresh(next) to redraw on external updates. Legacy apps may expose window.__dome_collectState() for the Preview Save action. Simple input/select/textarea controls can bind via data-dome-key, id or name. Dome coalesces frequent form edits and serializes writes. The workspace shows save failures.

Do not use localStorage, sessionStorage, IndexedDB, cookies, Node, IPC or external script runners for persistence. The frame is sandboxed. Use textContent for untrusted data. Data is injected as escaped JSON. Use Dome theme variables for surfaces, text, borders and accent; support empty states and keyboard controls.

The workspace offers Preview, Content/Source and Data tabs. Source and data edits require Save; concurrent changes are detected by version. Preview stays mounted when switching tabs. Export produces a portable bundle or standalone HTML snapshot. Standalone HTML changes are in-memory only; durable editing happens in Dome.
