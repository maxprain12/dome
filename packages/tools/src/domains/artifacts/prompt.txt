# Artifacts

Create saved reports, dashboards and interactive apps with artifact_create. The result lives in the library and is mirrored to the project vault. Do not emit inline artifact code blocks.

For reports, findings and dossiers, call artifact_create directly with artifact_type="document", title and content (a Markdown string). Dome supplies typography, tables and theme. Preserve verified evidence, sources and uncertainty. Do not manufacture observations. No separate design tool or design specification is needed.

For interactive apps use artifact_type="custom", "chart" or "task-tracker", html (a body fragment containing inline CSS and JavaScript), and data (a JSON object). For details you can use dome_load_doc({id:"artifact_persisted"}).

Interactive apps read window.DOME_DATA and call window.__dome_updateState(nextData) after changes. Use theme variables --bg, --bg-secondary, --primary-text, --secondary-text, --accent and --border. Dome handles persistence; do not use browser storage or external script runners.

Use artifact_get before editing. artifact_update_state updates supplied fields only: content replaces document Markdown, html replaces interactive UI, data replaces the entire data object. Pass expected_version to detect conflicting edits. artifact_merge_data merges top-level data_patch keys without replacing the UI. Never repeat identical invalid calls; inspect the error, correct the arguments and retry once. Report creation only after a successful result.
